# Lezzet Durağı

Lezzet Durağı, HTML ve CSS kullanılarak geliştirilen
mobil uyumlu bir restoran web sitesi projesidir.

## Projenin Özellikleri

- Modern ana sayfa tasarımı
- Navigasyon menüsü
- Görselli yemek kartları
- Yemek fiyatları ve açıklamaları
- Hakkımızda bölümü
- İletişim bölümü
- Mobil uyumlu tasarım
- Hover efektleri
- Yumuşak sayfa geçişleri

## Kullanılan Teknolojiler

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Media Queries

## Projeyi Çalıştırma

1. Proje dosyalarını bilgisayarınıza indirin.
2. Proje klasörünü açın.
3. index.html dosyasını tarayıcıda açın.

## Projenin Amacı

HTML ve CSS bilgilerini geliştirmek ve mobil
uyumlu bir restoran web sitesi oluşturmaktır.
